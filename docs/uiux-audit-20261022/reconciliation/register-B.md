## Notes

### B-05: what is persisted for a row whose toggle the instructor never tapped

The toggle always displays "Complete" for such a row.

- **Nothing else entered (any format, any environment):** `hasEntry` is false (`page.tsx:3409-3416`), so no result is written ("0 officer results recorded").
- **Qualification, Points, Time, Hit Count:**
  - PROD/STG: `completed:true` (forced, prod `:3406-3409`). `passed` is the override or the automatic value.
  - RC: `completed:true` (default `scoringFormat !== "Completion"`) and the same `passed`. The display matches the save.
  - After one tap ("Incomplete"): PROD still saves `completed:true` (the toggle is ignored). RC saves `completed:false, passed:false, finalPassed:false, departmentStandardPassed:false, remedialTrainingRecommended:true`.
- **Pass/Fail:** same as above. Result=Pass with an untouched toggle saves `completed:true, passed:true` in every environment.
- **Notes Only:**
  - Untouched: `completed:true`, `passed` undefined in every environment.
  - After one tap: RC saves `completed:false`, `passed` undefined, and **`departmentStandardPassed:false`, `deficiencyObserved:true`, `remedialTrainingRecommended:true`** (`:3465`, `:3517-3523`). The internal `finalPassed` is false even though the drill has no pass concept (B-R5).
- **Completion:**
  - PROD/STG: a note-only row saves `completed:false`, `passed` undefined. Result=Pass saves `completed:false, passed:true` (contradictory).
  - RC: both save `completed:false, passed:false, finalPassed:false, deficiencyObserved:true, remedialTrainingRecommended:true` while the card shows green "Complete" and "Pass".
  - In every environment, the only way to record Complete is to tap twice.
  - Readiness ignores incomplete attempts (B10 doc), so currency is not affected. The range-day record, the pass rate, `shouldRecommendRemedialTraining` (`app/lib/tracepoint/range-day-utils.ts:147-153`) and the qualifications "Remediation recommended" badge (for qualification/rifle drills) are affected.

### Merges (same root cause)

- **B-01 + B-21 + B-69:** the per-row status shows local state, not server acknowledgement. One per-row sync state fixes all three.
