# Local font assets

`geist-latin.woff2` and `geist-mono-latin.woff2` are the Latin variable-font
artifacts produced by the repository's prior `next/font/google` build. They are
now loaded with `next/font/local` so production builds preserve the existing
Geist typography without network access.

Geist is published by Vercel under the SIL Open Font License 1.1. Upstream
source and license: <https://github.com/vercel/geist-font>.

The complete license and upstream copyright notice are preserved in `OFL.txt`.
