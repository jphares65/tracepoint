### Re-baseline summary

- **First-pass findings (C-01 to C-62):** 53 Present, 9 Partly fixed, 0 Fixed in RC, 0 Obsolete.
  - Partly fixed: C-18, C-20, C-21, C-22, C-25, C-34, C-38, C-47, C-59.
- **OA refs:** 27 of the 62 carry one.
  - 7 are `=`: C-01 (ARM-14), C-03 (ARM-15), C-31 (ARM-03), C-32 (ARM-21), C-34 (ARM-22), C-59 (ARM-01 / FLT-04) and C-60 (OA terminology list).
  - 20 are `~`.
  - The other 35 are UX-only, and OA does not have them.
- **New findings: C-63 to C-70 (8).** One is High: C-63, the custody transfer on the record page always fails.
- **What the RC changes in this scope:**
  - **`/firearms` (+548 lines).**
    - New **Restricted** tab (Duty Only / No Carry restrictions, secure-storage Check In and Return to Officer, a searchable storage-location combobox with inline create).
    - The Custody card now shows **Assignment** and **Physical Custody** separately.
    - Edit and Status moved into a "…" overflow menu. Workspace tabs are now 40px tall.
    - Archive takes a **Not Returned Reason** for issued firearms (ARM-06).
    - The page reads `access.canManageRestrictions`, but no other access flags.
  - **`/firearms/[firearmId]` (+171 lines).** New "Physical Custody" section: current holder, the last 5 custody events, and a "Transfer to Secure Storage / Return to Assigned Officer" form. The form posts a contract the API no longer accepts (C-63). The page still has no issue/return, status, edit or documents (ARM-14).
  - **Server-side fixes (B8/B8a), no new UI:**
    - Inspection result rules: ARM-16. A Passed result now restores In Service (ARM-17).
    - Retired is refused while a firearm is issued: ARM-11.
    - Ammunition: actors are stamped (shown as "by <name>" in History), a count variance needs a reason, and a stale count returns 409 (ARM-21/22).
    - Reconciliation: expected quantities come from the server, and a second person must certify (ARM-23; the UI now tells the submitter "Submitted for command certification").
    - Self-review is blocked on off-duty requests and personal rifles (ARM-26/29). The UI still offers those actions (C-69).
  - **Elsewhere:**
    - Seven local `formatDate` copies were replaced by `src/lib/format/date` (DC). The off-duty "?" for empty dates is now "—".
    - QR: a server resolver accepts printed labels (B5), but labels still work only in the native app. There is still no firearm label, and the "Verified." / "open this vehicle" copy is unchanged.
  - **Unchanged except dates:** ammunition, reconciliation, the inspections pages, personal rifles, off-duty, `FirearmAttachments`, `TracePointQrLabel` and `OffDutyRulesPanel`. All the developer copy (C-04, C-06, C-13, C-56), the default-Pass checklist (C-03) and the "Unknown → In Service" fallback (C-02) are still there.

### Observed patterns (short; RC deltas in **bold**)

- **Headers and wrappers:** same as main. Off-duty builds its own `<header>` (`off-duty-firearms/page.tsx:1566`). `ArmoryPageHeader` and `ArmoryWorkspaceNav` are still never imported.
- **Buttons and radius:** still mixed. **The new Restricted tab adds rose primary buttons (`bg-rose-600`) for non-destructive saves, amber buttons for Check In, and violet buttons on the record page (`[firearmId]/page.tsx:602-613`). That is now four "primary" colours in one module (white, blue, rose/amber, violet).**
- **Reimplemented locally:**
  - Status badges, stat cards, banners and drawers are still local copies.
  - **`formatDate`/`formatDateTime` are consolidated into `src/lib/format/date` (DC batch).**
  - `readError` still has 4 copies.
  - **The restriction label is computed twice, with different words** (`firearms/page.tsx:242-252` against `[firearmId]/page.tsx:592`).
- **Feedback:**
  - The rest of the page still uses the top-of-page banner, `window.confirm` and `window.alert` (off-duty).
  - **The new restricted-use and custody actions give no success message at all. Errors from the Restricted tab go to the off-screen top banner (C-67).**
- **Two custody models now coexist.** "Assignment" (issue/return) and "Physical custody" (secure storage ↔ officer) are shown side by side. Physical custody is only initialised when a Duty Only restriction is set (`031:73-76`), so for most firearms it reads "Not recorded" (C-65).
