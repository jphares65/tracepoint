  1. **`settings/page.tsx`** changed only by about 110 lines:

  6. **Fleet rules:** the toggle copy now says critical safety holds always apply, so one toggle is inert (F6a).
  7. **Unchanged:** `/super-admin` UI, `SupportModeBanner`, `AdministratorButton`, `CreateAgencyForm`, the migration page and almost all of the import wizard UI. ### Observed patterns (short, RC)

- **One giant page with a strict tab model.** This is unchanged. `activeTab` is local `useState` (`page.tsx:733`), with no URL sync, search or anchors.
- **Global feedback is one `Notice`** (`page.tsx:2416–2417`), rendered under any open modal (`Modal` at `fixed inset-0 z-[80]`, `:571`). It is unchanged.
- **Five save models on one page now:**
  1. The header "Save {tab}" (`:2390–2411`, `saveCurrentTab` `:2325–2330`).
  2. Per-panel saves.
  3. Per-row saves.
  4. Immediate writes (Organization, patch, Super Admin).
  5. **New:** the immediate add, edit and deactivate actions of Secure Storage, which sit inside the Armory sub-tab while the header still offers "Save Rules Engine".
- **Confirmations:** `window.confirm` at `:2069` and `:2121`, plus `AgencyTrainingRulesPanel.tsx:87`, and `window.prompt` at `:1804`. Deactivate member, role permission changes, Make Administrator, module off, the migration bulk merges and Secure Storage Deactivate still have no confirmation.
- **Visual system:** unchanged. It is dark only, with hard-coded slate classes. There are 30+ `text-slate-600` hint and secondary texts on slate-900/950 (for example `:408`, `:536`, `:679`, `:3103`), and the new code adds more ad-hoc button and input classes (`SecureStorageLocationsPanel.tsx:209–262`).
- **Dev/vendor language:**
  - Removed: "saved to Supabase" and "managed through Supabase Auth".
  - Still present: "Modules should consume these rules…" (`:3347`), "Loaded permissions: N" (`:4530`), "Excel support can be added after we lock the field mappings" (`import-export/page.tsx:7261`), and the AI-importer jargon ("decision boundary", "approval fingerprint", "working-state fix(es)", "Minimized samples", "deterministic").
  - **New:** the admin-facing reset refusal "Cognito cannot send a reset code…" (`api/settings/users/password-reset/route.ts:182`).
